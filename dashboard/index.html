시세 수집

종목을 입력하고 누르면 야후에서 일봉을 받아 구글 드라이브 01_시세원본/<종목>/daily.csv에 저장합니다. 실제 처리는 GitHub Actions에서 진행되며 몇 분 걸릴 수 있습니다. 완료되면 이 화면이 자동으로 확인해서 알려주고, 아래 수집 결과 조회 표도 자동으로 새로고침합니다.

수집 결과 조회

종목별로 구글 드라이브에 시세가 실제로 저장됐는지, 언제 마지막으로 저장됐는지 확인합니다. 이 화면을 열면 자동으로 목록을 불러옵니다. 시세 수집 요청 직후에는 아직 진행 중일 수 있으니 잠시 뒤 새로고침하세요. '내용 보기'를 누르면 값 움직임 그래프와, 최근 2주·한 달·두 달과 가장 비슷했던 과거 구간, 그 구간이 끝난 뒤 같은 길이만큼 실제로 어떻게 됐는지까지 같이 보여줍니다.

종목상태마지막 저장(KST)

전략 비교

아래 값을 전부 직접 입력해야 계산됩니다. 미리 채워 둔 숫자는 시작값일 뿐이고, 바꾸지 않으면 그 값 그대로 씁니다. 계산이 끝나면 화면에 뜨는 것과 별개로, 종목·전략 조합마다 서식 있는 엑셀 파일을 구글 드라이브 02_백테스트결과/<종목>/에, 이번 비교 전체를 담은 엑셀을 02_백테스트결과/종목비교결과/에 올립니다. 계산이 끝나면 이 화면이 자동으로 확인해서 알려주고, 비교 결과 탭도 자동으로 새로고침합니다. '유사 과거 불러오기'를 누르면 DATA 수집 탭에서 이미 찾아 둔 유사 구간으로 조회기간을 바로 채울 수 있습니다.

비교할 전략 (최대 5개)

비교 결과

계산이 끝나면 여기서 불러올 수 있습니다. 요청 직후에는 아직 없을 수 있으니 잠시 뒤 새로고침하세요.

최적 조건 찾기

종목 하나와 총자본, 조회기간만 정하면 아래 네 가지 매수 방식의 여러 변수 조합을 한꺼번에 계산해서 수익률 순으로 보여줍니다. 후보값은 쉼표로 구분해서 넣고, 여기도 미리 채운 숫자는 시작값일 뿐이니 바꿔도 됩니다. 1등만 골라내지 않고 계산한 조합 전부를 순위대로 남깁니다. 등락률 기준 비중 조절 매수는 구간을 하나로 단순화해서 찾습니다(구간을 여러 개 두는 것은 전략 비교에서 직접 설정하세요). 매수 방식마다 익절선·손절선 후보도 따로 넣을 수 있습니다(방식마다 끝에 있는 칸입니다). 비워 두면 그 조건 없이 계산합니다. 조합이 200개를 넘으면 계산을 거부합니다. 계산이 끝나면 결과는 비교 결과 탭에서 그대로 조회됩니다. '유사 과거 불러오기'를 누르면 DATA 수집 탭에서 이미 찾아 둔 유사 구간으로 조회기간을 바로 채울 수 있습니다.
