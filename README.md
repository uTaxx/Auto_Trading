# Auto_Trading — 누적 매수 기법 전략 시뮬레이터

이 저장소는 `muwon406`(국내 단기 매매 시스템)과 완전히 분리된 새 프로젝트입니다.
계좌, 상태 저장소, GitHub Actions, n8n 워크플로를 공유하지 않습니다.

## 목적

미국 지수추종 ETF와 유망 섹터 ETF를 대상으로, 일회성 매수부터 적립식 매수,
이동평균선 조건부 매수까지 여러 매수·매도 방식을 과거 시세로 비교하는
백테스트 시뮬레이터를 만듭니다. 이후 일일 자동 매수 조건, 한국투자증권 API
연동까지 단계적으로 확장할 계획입니다.

## 지금 단계

1단계(시세 데이터 파이프라인)를 끝냈습니다. 대시보드에서 종목을 입력하고
누르면 n8n 웹훅을 거쳐 `update-prices.yml`이 야후 시세를 받아 구글
드라이브 `01_시세원본/<종목>/daily.csv`에 저장합니다. 도메인 위임을
걸어 둬서 새 종목도 사람 개입 없이 처리됩니다. 대시보드는 별도로 게시한
아티팩트 페이지입니다(링크는 대화 기록을 참고).

2단계(백테스트 비교 엔진)도 만들었습니다. `src/auto_trading/backtest.py`에
매수 방식 네 종류(일회 매수, 적립식 매수, 적립식+이동평균선 조건,
하락률 기준 비중 조절)가 있고, 이 중 다섯 개 조합을 등록해 뒀습니다
(`STRATEGY_FACTORIES`). `scripts/run_backtest.py`를 돌리면 종목별로
01_시세원본의 시세를 읽어 전략을 견주고, 총투자금·실현손익·평가손익·
합계를 표로 보여줍니다. `--upload`를 주면 시계열 전체를
02_백테스트결과에 JSON으로 남깁니다. GitHub Actions에서
`workflow_dispatch`로 손으로 돌릴 수 있습니다(`run-backtest.yml`).

다음은 이 비교 결과를 보여주는 화면(대시보드나 아티팩트)을 만드는
것입니다. 아직 시세가 몇 종목 안 쌓여서 화면보다 데이터를 더 모으는
것이 먼저입니다.

## 원칙

- 최소한의 구조로 시작하고, 기능은 하나씩 검증하면서 늘립니다.
- 실제 주문과 연결되기 전까지는 백테스트와 데이터 수집에 집중합니다.
- 구글 드라이브, 텔레그램 봇, GitHub Actions 계정은 muwon406과 새로
  분리해서 씁니다.
